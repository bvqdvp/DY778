# DY778

iOS 抖音增强插件，提供消息留存、编辑历史、特别关注、直播信息、福袋助手、直播自动点赞、星牌查询、操作确认、数字自定义、聊天火花、列表清理和播放增强。

当前版本 `1.0-3`，构建目标为 iOS `14.0+`、`arm64`。入口位于 **抖音设置 → DY778**，增强功能首次安装默认关闭，可按需开启。

**仅在抖音 `39.9.0` 测试，其他版本请自行测试。** 如遇闪退或功能失效，欢迎提交 [Issue](https://github.com/jijiang2333/DY778/issues)，并附上抖音版本、iOS 版本、安装方式和复现步骤；有修复或改进方案，也欢迎提交 [Pull Request](https://github.com/jijiang2333/DY778/pulls)。

开源仓库：[https://github.com/jijiang2333/DY778](https://github.com/jijiang2333/DY778) · Telegram 频道：[https://t.me/JiJiang_778](https://t.me/JiJiang_778)。

## 功能

### 消息防撤回

- 留存本机已收到的消息，支持按会话单独开关。
- 展示文字、图片、表情、语音、视频和分享卡片中的可用信息，分享作品可跳转原作品。
- 分享评论与对应作品一起展示，保存首次取得的评论文字、作者及可用的评论编号，后续删除提示不会覆盖已留存文字。
- 自定义撤回标记文字、位置和气泡颜色。默认保留气泡皮肤，可开启“撤回后使用普通气泡”；图片、视频和表情画面保持原样。
- 支持撤回提醒、按会话查看，以及删除单条、单个会话或当前账号的全部记录。

### 编辑历史

- 独立开关，支持按会话控制。
- 保存本机收到的原文及后续编辑版本，展示原消息时间、编辑时间和本机留存时间。
- 自定义标记文字、位置及气泡颜色。染色默认关闭，关闭后保留原色；同一消息也已撤回时，已开启的撤回底色优先。
- 可从插件设置、聊天信息页或消息旁的标记进入历史。
- 可选编辑提醒，前台显示横幅，后台实际收到事件时发送本地通知，点按进入对应历史。通知及内容摘要均默认关闭，重复事件不重复提醒。

首次收到时已经编辑的消息会标注未取得原文。启用前、离线或应用未运行期间未收到的版本无法补回。撤回和编辑提醒依赖抖音运行状态及系统通知权限。

### 聊天时间标签

自定义时间格式、字号、颜色、背景、透明度和位置，支持智能日期及隐藏官方时间提示。时间、撤回和编辑标记可分别设置位置，并在空间不足时自动避让。

### 福袋助手

处理当前前台直播间的普通福袋，支持确认后参与或自动参与，显示奖品、倒计时和参与条件。

开启自动评论后可发送指定口令。不自动消费、赠礼、点亮或升级粉丝灯牌；资格不满足或无法确认时跳过。切换直播间、进入后台或关闭开关会取消当前任务。

### 直播自动点赞

默认关闭，仅在当前前台直播间运行。开启后，在直播画面双击开始一轮，再次双击可随时停止。

- **每轮次数**：`1–9999` 次，默认 `100` 次。
- **点赞间隔**：`0.6–2` 秒，默认 `1` 秒。
- **每 20 次休息**：`1–3` 秒，默认 `1.5` 秒。间隔和休息时间均以 `0.1` 秒调整。

每完成 20 次自动点赞，下一次间隔取“点赞间隔”和“休息时间”中的较大值，之后恢复普通点赞节奏；休息时间不额外叠加。等待提交反馈时，实际停顿可能更长。

顶部仅显示一行 `自动点赞中 x/xxx`，表示本轮已执行次数与目标次数，不包含触发时的手动双击。达到目标后继续等待本轮提交结果，确认完成后提示自动收起。直播间总数还包含其他观众，并受刷新节奏及平台计数规则影响，实际增量以直播间显示为准。

离开或切换直播间、进入后台、修改次数或节奏、关闭开关都会结束本轮，返回后需重新双击。提交失败、连续未响应或长时间没有反馈时也会停止，不会无限重试。

**使用建议**：间隔和休息时间越短、连续使用越频繁，越容易触发抖音的频率限制或风控，可能出现延迟、少计或暂停。建议优先使用默认节奏，按需设置次数；如遇异常，可延长间隔或休息时间、稍后再试。次数上限与短暂停顿用于控制连续操作，不代表免受风控，也不保证每次操作均被平台计入。

### 视频播放

- **默认倍速**：可选 `1.25×`、`2×`、`2.5×`、`3×`，支持 `1–3×` 的自定义值，最多两位小数。直播和图文不调整。
- **播放结束暂停**：视频作品播放结束后自动暂停。
- **长按倍速**：使用抖音原有的长按加速手势，支持 `1–3×`，默认 `2×`。

### 推荐页直播信息

- **在线人数**：在推荐页直播卡片显示当前可读取的人数，支持简洁和完整格式，刷新间隔可设为 `2–10` 秒。
- **开播时长**：单独开关，显示该场直播已开播的时间。

两项各自使用独立的小胶囊，仅显示图标和数值，图标颜色不随插件点缀色改变。简洁人数保留“万”“亿”单位，也可选择完整数字。卡片停稳后显示；同时开启时上下排列并留出间距，单独开启时只显示对应项。切换卡片、进入直播间或退到后台后会停止原卡片的更新。未取得可靠数据时暂不显示对应项，不用零值代替缺失信息。人数与时长取决于抖音返回的数据，可能存在更新延迟或部分直播不可用。

### 直播间开播时长

在 **直播信息 → 直播间浮层** 开启。默认居中靠上放置，可拖动调整，横屏和竖屏分别记忆位置；支持文字大小、文字颜色、背景颜色及不透明度设置，也可恢复默认位置。

只展示当前直播间已取得的开播时间。离开直播间、退到后台或关闭开关后停止更新。该项与推荐页卡片时长分别控制；直播间浮层的自定义样式不会影响推荐页胶囊。

### 特别关注

在独立设置页选择关注对象，最多 `20` 人，支持从互关好友选择或输入抖音号核对后添加。检测获赞、关注、粉丝、喜欢数量、个人简介及可读取的喜欢作品变化，保存动态档案，可选择是否弹窗提醒。

- 默认 `300` 秒检测间隔，支持 `30–300` 秒；多人依次排队，异常时自动减慢，仅在抖音前台运行。
- 聊天右上角的信息页可单独开启或暂停对此人的特别关注，需先开启总开关。暂停保留已有记录。
- 首次成功读取用于建立基线，不将已有内容当成新变化；账号切换后分别使用各自的设置与档案。
- 档案默认保留 `7` 天、最多 `500` 条，可调整保留规则、删除单条或清空当前账号的档案。

仅记录当前账号有权查看且实际取得的信息，无法读取的私密或受限内容不会补全。发现时间不等于实际操作时间，数量变化也不能用于推断具体关注关系。检测间隔不代表固定完成周期，后台期间不会持续检测或补发请求。

### 星牌查询

开启后在用户主页显示 **星牌** 按钮，点按查询该用户可读取的消费等级和粉丝灯牌；选择主播后，可核对对应的灯牌资料。设置中只有一个总开关，查询对象来自当前主页。

结果以当前登录状态和可返回数据为准。未返回信息不等于没有加入粉丝团，等级区间不代表实际消费金额。查询结果不作为本地历史保存，支持复制本次结果；退出查询、切换账号或关闭功能会停止当前任务。

### 操作确认

作品点赞、收藏、关注、评论点赞和评论点踩分别设置开关。开启后使用紧凑确认弹窗，根据当前状态区分执行操作与取消已有操作；点击“暂不操作”或弹窗外区域取消本次操作。

确认前会复查对应内容与状态，内容已变化、切换账号或退到后台时不会继续执行。评论状态暂无法读取时会提示重试。适配依赖宿主页面与接口，不同抖音版本的入口可能有所差异。

### 主页与作品数字

在 **显示与整理 → 主页与作品数字** 开启 **启用数字自定义**，已填写的主页与本人作品数字即可生效，无需再开启分组开关。支持主页的获赞、互关、关注和粉丝数，以及本人作品的点赞、评论、收藏、分享和播放数。仅改变当前账号在本机看到的数字，不会修改真实互动、关系列表或其他人看到的结果。

- **主页快捷编辑**：长按本人主页对应数字或其下方文字，直接编辑该项，触发范围限定在该项内。普通点击仍使用抖音原有入口；获赞弹窗与有计数的本人关系页标题同步显示设置值。
- **按作品管理**：在插件设置中进入 **按作品单独设置**，选择作品后修改五项数字。列表收录本次已浏览的本人作品及已有配置的作品，不同账号、不同作品分别保存。单作品数值优先于通用数值，单项留空表示跟随通用设置。作品播放页不提供长按编辑入口。
- **下拉恢复**：启用时，手动下拉刷新 **我** 页，会清除当前账号的全部数字设置并显示提示，包括主页四项和作品的点赞、评论、收藏、分享、播放量，以及通用与单作品配置。总开关保持开启，可继续重新设置。进入页面、切换标签或自动刷新不会触发此恢复。
- **其他恢复方式**：关闭总开关恢复原值并保留配置。单作品的 **此作品使用原始数字** 可绕过通用及单作品数值；**清除并恢复原始数字** 清除该作品的自定义数值并使用原值，**跟随通用设置** 则回到通用规则。**恢复当前账号原状** 清除当前账号的全部数字配置，总开关保持原状态。

数值支持 `0–999999999` 的整数，沿用抖音已有的计数位置和样式，不额外创建原界面没有的数字位置。通用设置留空时沿用原值，页面及编辑入口以当前作品和账号的实际绑定为准。

### 聊天火花

在 **消息 → 聊天火花** 开启总开关，再从单聊或群聊右上角信息页进入 **自定义火花**。可单独开启该聊天的显示设置，选择点亮或熄灭，并设置 `1–99999` 天。支持原生火花入口的已点亮、已熄灭和“点亮中”状态，沿用抖音原生图标与布局。

设置按账号和会话分别保存，仅改变本机显示，不增加真实火花天数、奖励或改变对方看到的内容。聊天顶部、会话列表及已适配的原生详情同步更新；部分详情容器未能建立对应关系时，可关闭详情后重新进入。没有原生火花展示位置的聊天不会额外创建火花图标或详情入口。

关闭总开关或该聊天开关可恢复原始显示并保留设置。聊天内的 **恢复此聊天原状** 仅清除当前会话配置；插件内的 **恢复当前账号全部火花**，以及消息页右上角 **＋ → 恢复火花显示**，均清除当前账号全部会话的火花配置，保留总开关与其他账号设置。恢复后设置页和已适配的显示页面同步更新。

### 列表清理

在 **显示与整理 → 列表清理** 开启 **长按清空列表** 后，回到“我”页，长按 **推荐**、**收藏** 或 **喜欢** 标签，确认后处理对应作品列表，无需先切换到该标签。普通点击仍保持原来的用法，功能默认关闭。

这会实际取消当前账号的推荐、作品收藏或喜欢，不会删除作品，也无法一键撤销。收藏清理不涉及音乐、地点等其他分类。仅处理本次可完整读取且可取消的作品，失效或不可见内容可能需要手动处理。

确认后留在当前主页，顶部提示读取与清理进度，可点击提示中的 **停止** 结束后续处理。先完整读取列表，再分批取消，进度仅计入已核对的结果；完成时显示勾选动画并提供触感反馈。关闭开关、离开本人主页、切换账号、退到后台、超时或遇到无法确认的结果时会停止后续处理。已经提交的请求可能继续完成，已成功的取消会保留；结束后请刷新原列表查看实际结果。平台可能限制操作频率，遇到异常请稍后再试，不会自动反复重试。

### 缓存管理

查看缓存用量，支持手动清理、容量或时长限制，以及启动清理和返回前台清理。

清理范围包括应用缓存、临时文件、页面资源、投屏缓存和日志，保留识别到的插件配置及消息档案。时长设为「从不」不影响容量限制，容量 `0` 表示不限。缓存用量不等于系统显示的应用总占用。

### 实验功能：跳过疑似广告

默认关闭，仅作用于首页推荐流。根据明确广告标记及多项推广信息判断，已关注、点赞、收藏和自己的作品优先保留；不因单个品牌名、商品标签或价格直接跳过。

不处理搜索、个人主页、聊天分享或直播，跳过的作品仍可返回查看。识别依据为本机可读取的作品字段和标题，可能存在误判或漏判。

## 记录与媒体

撤回记录和编辑历史保存在应用的持久数据目录，与缓存目录分开。保存天数和数量上限默认均为 `0`，不自动过期；手动删除、设置保留限制或清除应用数据仍会删除记录。同一应用内升级 DY778 时沿用已有设置和档案。

本插件的缓存清理保留上述记录。其他工具若只清理缓存，通常不会影响记录；若直接删除持久数据目录或清空整个应用数据，插件无法阻止或恢复。

媒体文件与文字记录不同：插件不持续下载或永久缓存附件，预览使用抖音现有的本地附件或仍有效的远程地址；视频用原视频预览画面，封面不会作为视频播放。媒体不可读时，可从记录定位原会话中的消息，并短暂高亮整行；原消息也已不在抖音本地记录中时，仍可查看已留存的消息文字与分享评论。抖音媒体缓存被清理、链接失效或作品删除后，媒体可能无法打开。分享评论只保留首次实际取得的文字或语音转写，不能恢复此前没有收到的内容。

## 安装与构建

预编译文件位于仓库的 `packages/` 文件夹：

- `packages/DY778-1.0-3-rootless.deb`：用于支持插件注入的 rootless 环境。
- `packages/DY778.dylib`：由相应注入工具加载。

两者包含相同的动态库，按使用环境选择一种安装方式，避免重复加载。安装或替换后重新打开抖音。

应用识别覆盖抖音与抖音极速版的 Bundle ID，并兼容可执行文件名为 `Aweme` 或 `AwemeHM` 的签名包。可执行文件名指应用内部的主程序名称，修改 IPA 文件名或桌面显示名称不会改变此项识别。极速版及其他重签包的具体功能兼容性仍需按实际版本测试；加载范围不等于所有功能均已验证。

源码构建需要 Theos 和 iOS 16.5 SDK。在源码根目录执行：

```sh
make package
```

编译目标见 [Makefile](Makefile)，构建时间自动记录为 UTC+8。

也可在 GitHub 的 **Actions → Build DY778 → Run workflow** 中手动构建。完成后从该次运行的 Artifacts 下载 `DY778-rootless`，包含 deb 和 dylib。工作流仅支持手动触发，推送代码或提交 PR 不会自动构建。
